client. The source is licensed under the Apache License, Version 2.0. The adapted
file contains a prominent modification notice. Pegas uses its own generated

## Tabler Icons worker glyphs

The car, camera, computer and phone Worker glyphs rendered by
`scripts/generate-agent-icons.mjs` adapt outline path geometry from Tabler
Icons. The source paths are used unmodified inside a shared scaling
transform; the rounded-square background, brand colors and the Pegas bot
glyph are Pegas's own design.

Source: [tabler/tabler-icons](https://github.com/tabler/tabler-icons),
