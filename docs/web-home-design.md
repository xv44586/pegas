# Pegas Web 首页设计

> Feature：CONV-002
>
> 状态：Usable
> 更新日期：2026-11-18

## 用户结果

用户打开 Pegas Web 后，不需要先理解 Task、Run、模型或工具，就能立即说出一个目标；同时可以看见 Pegas 是否在线、已有事情是否在推进，以及敏感操作会如何处理。

## 验收条件

1. 对话输入是首页主操作，首屏可直接键盘输入、听写、打开附件说明或选择一个意图模板。
2. 空对话页说明 Pegas 会自动组织任务，并展示进行中任务数量、执行可追踪与高风险动作先确认三个信任线索。
3. 左侧导航在对话、任务与设置三个页面间切换；任务页面按待安排、未开始、进行中、已完成和已取消分组，状态、数量和更新时间可直接扫读。
4. 右侧工作区不承载全局任务列表，只展示当前任务现场、最近生成内容或后续侧聊；桌面端可开关，小于 `820px` 时以全屏对话框呈现且不产生横向滚动。
5. 设置页面集中呈现模型、路由、语音输入、隐私与改写边界；只保存现有服务端设置，不在浏览器创造新的权威配置。
6. 所有操作使用原生按钮、表单和标签；键盘焦点清晰，触摸设备上的主要按钮目标不小于 `44px`，动态状态通过 `aria-live` 或可见文本表达。
7. 动效只使用 `opacity` 与 `transform`，持续时间为 `150–300ms`；减少动态效果时保持最终状态且不使用全局 `0.01ms` 覆盖。
8. 现有消息、语音听写、任务详情、设置、鉴权和 URL 深链行为保持可用。

## 非目标

- 不新增服务端状态、任务类型或 Router 决策。
- 不新增可编辑项目、优先级或状态拖拽；任务看板只是服务端状态的可读投影。
- 不新增主题账户同步、通知中心或审批领域对象。

## 数据与权限边界

- 首页只读取服务端 Snapshot、Settings 和现有消息接口，不在浏览器推导权威任务状态。
- 快捷入口只预填用户可编辑的文本，不自动发送，也不替用户扩大执行授权。
- 令牌仍只存于当前 `sessionStorage`；设置仍由服务端持久化并通过 revision 防止覆盖。

## 失败与恢复

- Snapshot 失败时保留输入内容，显示原因与“重新连接”操作。
- 发送失败时保留草稿并允许重试；发送中禁用重复提交。
- 移动端工作区可用关闭按钮或 `Escape` 返回触发位置。

## 视觉系统

本轮验收：统一浅色导航与工作面；任务页使用紧凑工具栏及真实任务搜索；列头通过不同形状图标和文字表达状态；卡片按编号、标题、属性分层；鼠标按钮采用 34–40px 控件，触摸设备扩大至至少 44px。所有图标保留可访问名称，状态不能只用颜色区分。

- **方向**：Quiet intelligence（安静、可信、编辑感），避免霓虹、重玻璃和装饰性渐变。
- **颜色**：白色工作面、冷浅灰导航、低对比分隔线，状态局部使用青绿与琥珀色。
- **字体**：Inter Variable；正文 `16px/1.6`，标题采用紧凑字距与克制字重。
- **形状**：按钮圆角 `6px`、任务卡片 `7px`、输入器 `26px`；统一 16–17px 线性图标，以细边框为主，弱化阴影。
- **节奏**：4/8px 间距系统；正文最大阅读宽度约 `72ch`。

## 验证证据

- `web/src/App.test.tsx`：7 个 Web 回归场景通过，覆盖自然对话入口、快捷意图预填、任务看板与工作区、语音草稿、送达元数据、Markdown 和设置。
- `pnpm check`：19 个测试文件、76 个测试全部通过；格式、Lint、类型、Knip、覆盖率、服务端与 Web 构建通过。
- `pnpm smoke`：Control Plane、Echo Worker、Notification Dispatcher、Web 静态客户端和完整任务回路通过。
- Playwright：在 `1440×960` 验证对话、任务看板、设置和可关闭工作区；在 `375×812` 验证顶部导航、横向看板、工作区初始焦点、`Escape` 关闭和触发点焦点恢复。
- 浅色细化轮次：使用浏览器请求拦截注入 6 个示例任务检查卡片密度，截图仅作视觉证据；示例未持久化。新增任务搜索及清空搜索的回归断言，76 个测试及 smoke 通过。

## 剩余风险与回滚

- 仍需在真实 iOS Safari、Android Chrome 和屏幕阅读器上做实机无障碍验证。
- 回滚只需撤销 CONV-002 首页提交；本次没有数据库、API 或持久化格式变化。

## 输入器细化验收（CONV-002）

- 输入器为单层白色圆角容器，轻边框与阴影；聚焦反馈只作用于外框，内部 textarea 不出现第二层描边。
- 输入区不重复显示标签，但保留关联的无障碍 label；默认提示“和 Pegas 一起工作”。附件入口位于左下，麦克风与黑色圆形发送按钮位于右下。
- 支持原生自适应高度，最多 10 行，旧浏览器回退到可滚动、可纵向调整的 textarea；保持宽度稳定。
- 空白输入不可发送；中文输入法确认与 Shift+Enter 不发送；录音反馈可见，失败保留草稿。
- 不新增模型选择、权限等级、停止执行等尚未接入的能力，不改变服务端输入、语音与权限边界。附件继续说明当前能力。
- 验证：组件测试覆盖键盘与失败草稿；真实浏览器核对焦点、长内容、手机布局及按钮尺寸。回滚仅撤销本次 CONV-002 提交。

本轮验证：`pnpm check` 通过，19 个文件 / 77 个测试；桌面 1440×960 与手机 375×812 实测聚焦及按钮布局。语音沿用现有自动化测试，尚未做真实麦克风重测。
